# AGENTS.md

이 파일은 이 저장소에서 작업하는 AI 코딩 에이전트(Codex, Claude Code 등)를 위한 공통 안내서입니다. `CLAUDE.md`는 이 파일을 불러오므로, 프로젝트 안내는 이 파일 한 곳에서만 수정합니다.

## 프로젝트 개요

20년차 개발자 본인을 소개하는 **한 페이지(one-page) 홈페이지**입니다. 포트폴리오와 개발 역량을 알리는 것이 목적입니다.

이 디렉터리는 빈 상태에서 시작합니다. 아직 빌드 도구, 패키지 매니저, 테스트가 없으므로 존재하지 않는 명령(npm 스크립트 등)을 가정하지 않습니다.

## 핵심 제약

- **데이터베이스 연결 없음.** DB, 서버 측 저장소, 백엔드 API를 도입하지 않습니다. 프로필, 경력, 프로젝트, 기술 스택 등 모든 콘텐츠는 정적 파일(HTML 마크업 또는 같은 저장소의 JS/JSON 데이터)로 관리합니다.
- **한 페이지 구성.** 섹션 간 이동은 같은 문서 안의 앵커(`#about`, `#projects` 등)로 처리합니다.
- 페이지 언어는 한국어입니다(`<html lang="ko">`).

## 주변 저장소 관례 (상위 폴더 `D:\ChaAI`)

- git 저장소 루트는 이 폴더가 아니라 상위 폴더 `D:\ChaAI`입니다. 해당 `.git`의 소유자가 다른 Windows 계정(CodexSandboxOffline)이라, 다른 계정에서는 git 명령이 "dubious ownership" 오류로 실패할 수 있습니다. 해결하려면 `git config --global --add safe.directory D:/ChaAI`가 필요하며, 실행 전에 사용자에게 먼저 확인합니다.
- 상위 폴더의 기존 결과물(계산기 등)은 **빌드 단계 없는 단일 정적 HTML 파일**이며, Vercel에 정적 사이트로 배포됩니다(`D:\ChaAI\vercel.json`: `framework: null`, `buildCommand: ""`, `outputDirectory: "."`). 별도 지시가 없으면 이 프로젝트도 같은 방식(빌드 없는 정적 HTML/CSS/JS)을 따릅니다.

## 로컬 확인

빌드 단계가 없으므로 `index.html`을 브라우저로 직접 열거나 정적 서버로 띄워 확인합니다. 예:

```
npx serve .
```
