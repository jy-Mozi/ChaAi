# PRD: 개인 소개 원페이지 홈페이지

- 문서 상태: 초안
- 작성일: 2026-10-13
- 참고: `AGENTS.md` (프로젝트 지침)

## 1. 배경과 목적

20년차 개발자인 본인을 소개하고, 포트폴리오와 개발 역량을 알리는 한 페이지짜리 웹사이트를 만든다. 방문자가 한 번의 스크롤로 "어떤 개발자인지, 무엇을 만들어 왔는지, 어떻게 연락하는지"를 파악할 수 있어야 한다.

## 2. 대상 사용자

| 대상 | 기대하는 것 |
|---|---|
| 채용 담당자·헤드헌터 | 경력 요약, 핵심 역량, 연락처를 빠르게 확인 |
| 잠재 고객·협업 파트너 | 수행 프로젝트와 결과물, 문제 해결 방식 확인 |
| 동료 개발자 | 기술 스택, 코드 저장소, 기술 글 확인 |

## 3. 목표와 비목표

### 목표
- 첫 화면에서 이름, 직함, 한 줄 소개, 연락 수단이 바로 보인다.
- 20년 경력을 시기별로 한눈에 볼 수 있다.
- 대표 프로젝트를 역할·기술·성과 중심으로 보여준다.
- PC와 모바일에서 모두 읽기 편하다.

### 비목표
- 데이터베이스, 백엔드 API, 서버 측 저장소 (지침상 사용하지 않음)
- 로그인, 관리자 페이지, 방문자 댓글·게시판
- 여러 페이지로 구성된 사이트 (한 페이지만 만든다)

## 4. 페이지 구성 (섹션)

섹션 간 이동은 상단 고정 내비게이션의 앵커 링크로 처리한다.

| 순서 | 앵커 | 섹션 | 내용 |
|---|---|---|---|
| 1 | `#hero` | 첫 화면 | 이름, 직함, 한 줄 소개, 주요 버튼(포트폴리오 보기, 연락하기) |
| 2 | `#about` | 소개 | 개발 철학, 강점, 경력 요약 수치(경력 연수, 프로젝트 수 등) |
| 3 | `#skills` | 기술 스택 | 분야별(언어, 프레임워크, 인프라, 도구 등) 기술과 숙련도 |
| 4 | `#experience` | 경력 | 연도별 타임라인: 회사·기간·역할·주요 성과 |
| 5 | `#projects` | 포트폴리오 | 프로젝트 카드: 제목, 기간, 역할, 사용 기술, 성과, 링크 |
| 6 | `#contact` | 연락처 | 이메일, GitHub, 블로그, LinkedIn 등 외부 링크 |

## 5. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| F-1 | 상단 고정 내비게이션, 클릭 시 해당 섹션으로 부드럽게 스크롤 | 필수 |
| F-2 | 모바일 화면에서 내비게이션을 메뉴 버튼으로 접기 | 필수 |
| F-3 | 프로젝트 카드를 기술 분야별로 필터링 | 선택 |
| F-4 | 프로젝트 카드 클릭 시 상세 내용 펼치기(모달 또는 아코디언) | 선택 |
| F-5 | 이메일 주소 복사 버튼 | 선택 |
| F-6 | 라이트/다크 테마 (시스템 설정 따르기 + 수동 전환) | 선택 |

연락 폼처럼 서버 저장이 필요한 기능은 넣지 않는다. 연락은 `mailto:` 링크와 외부 프로필 링크로 대신한다.

## 6. 콘텐츠·데이터 관리

- 모든 콘텐츠는 정적 파일로 관리한다 (지침: DB 연결 없음).
- 경력·프로젝트·기술 스택처럼 반복되는 항목은 JS 데이터(배열/객체)로 분리해, 항목 추가 시 데이터만 고치면 화면에 반영되게 한다.
- 이미지(프로필 사진, 프로젝트 스크린샷)는 저장소 안에 함께 둔다.

### 필요한 콘텐츠 (사용자 제공 필요)
- [ ] 이름, 직함, 한 줄 소개
- [ ] 프로필 사진
- [ ] 개발 철학·강점 소개 글
- [ ] 기술 스택 목록
- [ ] 경력 이력 (회사, 기간, 역할, 성과)
- [ ] 대표 프로젝트 (제목, 기간, 역할, 기술, 성과, 링크, 이미지)
- [ ] 연락처 및 외부 링크

## 7. 비기능 요구사항

- **기술 구성:** 빌드 단계 없는 정적 HTML/CSS/JS (지침의 상위 폴더 관례를 따름).
- **언어:** 한국어 (`<html lang="ko">`).
- **반응형:** 모바일(360px)부터 데스크톱까지 가로 스크롤 없이 표시.
- **성능:** 외부 라이브러리를 최소화하고, 이미지는 적절한 크기로 최적화.
- **접근성:** 시맨틱 태그 사용, 이미지 대체 텍스트, 키보드로 내비게이션 가능, 충분한 색 대비.
- **검색·공유:** `<title>`, `meta description`, Open Graph 태그 설정.

## 8. 배포

상위 폴더(`D:\ChaAI`)의 기존 결과물과 같이 Vercel에 정적 사이트로 배포한다. 빌드 명령 없이 폴더 그대로 배포한다.

## 9. 완료 기준

- [ ] 6개 섹션이 모두 실제 콘텐츠로 채워져 있다.
- [ ] 내비게이션의 모든 앵커 링크가 해당 섹션으로 이동한다.
- [ ] 모바일·데스크톱에서 레이아웃이 깨지지 않는다.
- [ ] 모든 외부 링크가 정상 동작한다.
- [ ] 배포 URL에서 페이지가 열린다.
